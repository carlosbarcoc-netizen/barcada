# El estilo 2D (ilustración con volumen)

Con `"estilo": "2d"` en `proyecto.json`, cada toma lleva un `dibujo` en lugar de una `imagen`: piezas ilustradas
(contorno entintado, sombra de dos tonos, luz de borde y grano) que entran, se mueven y cambian **al ritmo de la voz**.
No hay que buscar ni pagar imágenes. El muestrario de todas las piezas: `node nucleo/2d/muestrario.mjs muestrario`.

## Una toma 2D

```json
{ "desde": "2:mazorca", "rotulo": "TODO EMPIEZA EN LA *MAZORCA*",
  "dibujo": {
    "fondo": "naturaleza",
    "camara": [[0, { "zoom": 1 }], ["2:granos", { "zoom": 1.3, "x": 600, "y": 900 }]],
    "elementos": [
      { "pieza": "arbol", "x": 220, "y": 1150, "escala": 1.1, "entra": "crece", "en": 0 },
      { "pieza": "mazorca", "x": 600, "y": 950, "escala": 1.5, "entra": "rebote", "en": "2:mazorca",
        "params": { "abre": [["2:abre", 0], ["2:granos", 1]] } }
    ] } }
```

- **Cuándo** (`en`, `hasta`, claves de `camara`, `mueve` y `params`): segundos desde que empieza la toma (`0.4`) o
  una palabra de la voz (`"frase:palabra"`, o `"palabra#2"` para la segunda vez que se dice).
- **Dónde:** el cuadro mide 1080 × 1920. Lo importante, entre y 600 y 1350 (arriba van los subtítulos y abajo los
  rótulos); el suelo de los fondos está hacia y 1380-1500.
- **escala:** 1 ≈ 400 px de alto. Lo principal, grande: escala 1,2-1,8.

## Las piezas (`pieza`) y sus parámetros

| Grupo | Piezas | Parámetros que se animan |
|---|---|---|
| Comida y agro | `taza`, `mazorca`, `grano`, `chocolate`, `hoja`, `planta`, `arbol`, `gota`, `frasco` | `vapor`, `abre`, `estado` (0 fresco → 3 tostado), `pulpa`, `tipo` (cacao/cafe), `partida`, `crece`, `lleno` |
| Cuerpo y salud | `cerebro`, `corazon`, `celula`, `mano`, `persona` | `brilla`, `late`, `gesto` (palma/senala/pulgar), `pose` (quieta/saluda/piensa/celebra) |
| Dinero | `moneda`, `billete`, `grafico`, `alcancia` | `gira`, `signo`, `valores`, `crece`, `tendencia` |
| Tecnología | `celular`, `laptop`, `bombilla`, `engranaje`, `robot` | `pantalla` (texto), `encendida`, `gira` |
| Naturaleza y ciencia | `sol`, `luna`, `planeta`, `nube`, `rayo`, `fuego`, `montana`, `molecula`, `lupa`, `reloj` | `tierra`, `anillo`, `hora` |
| Lugares y cosas | `casa`, `fabrica`, `caja` | — |
| Signos y textos | `flecha`, `signo`, `numero`, `texto` | `largo`, `tipo` (check/x/distinto/igual/mas/pregunta/exclama), `texto`, `tamano` |

Cualquier pieza acepta `color` (una paleta: `rojo`, `verde`, `azul`, `amarillo`, `naranja`, `rosa`, `morado`, `agua`,
`oro`, `metal`, `madera`, `papel`, `gris`, `negro`, `blanco`, `cafe`, `cacao`, `piel`…), `rot` (grados), `capa`
(más alto, más delante) y `opacidad`.

## Cómo se mueven

- **entra** (en `en`, dura `dura` s): `aparece`, `rebote`, `cae` (bota al llegar), `sube`, `izquierda`, `derecha`,
  `crece`, `gira`, `ninguna`.
- **sale** (en `hasta`): las mismas, al revés.
- **accion** (todo el rato): `flota`, `late`, `gira` (`velocidad` en grados/s), `tiembla`, `balancea`.
- **mueve:** claves de posición `[["3:baja", { "x": 300, "y": 1100, "escala": 0.8, "rot": 10 }]]`.
- **params:** un valor fijo (`"abre": 1`) o claves (`"abre": [["2:abre", 0], ["2:granos", 1]]`).
- **camara:** claves de `{ zoom, x, y }` (el centro que mira). Zoom 1-1,4; acercarse a lo que nombra la voz.

## Fondos (`fondo`)

`estudio` (cálido, mesa), `cielo`, `naturaleza`, `noche`, `espacio`, `cocina`, `oficina`, `oscuro`, `liso`
(`fondoOpts: { "paleta": ["#color1", "#color2"] }`). `fondoOpts.suelo` cambia la altura del suelo.

## Reglas para que se vea bien

- **Algo pasa en cada frase:** una pieza entra, cambia o se mueve en la palabra que la nombra.
- **Una idea, una toma.** Toma nueva cada 3-6 s (en 2D cada toma puede tener mucho movimiento dentro).
- **Lo principal, grande y en el centro;** como mucho 3-4 piezas a la vez.
- Las comparaciones, con dos piezas a los lados y un `signo` en medio (`distinto`, `igual`).
- Las cifras, con `numero`; los pasos de un proceso, con `flecha` entre piezas o con el `rotulo`.
- Si falta una pieza para el tema, construye la escena con las que hay (una «fábrica» + «engranaje» + «flecha»
  explican casi cualquier proceso) y apunta en `aprendido.md` qué pieza nueva haría falta.
