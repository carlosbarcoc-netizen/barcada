# Tu Jarvis gratis con OpenJarvis

Tema tomado del reel de referencia del usuario (arcade, «Open Jarvis»). Guion propio. Firma: @carlosbarcoc. CTA: «Comenta VIRAL…».

## Datos (cada uno con su fuente)

- OpenJarvis se desarrolla en Hazy Research y el Scaling Intelligence Lab de Stanford SAIL. — https://github.com/open-jarvis/OpenJarvis
- Licencia Apache 2.0 (código abierto, gratis). — https://pypi.org/project/openjarvis/ y el README
- «Personal AI agents that run locally by default, calling the cloud only when truly necessary»; el instalador monta Ollama y un modelo local. — README
- Instalación en una línea: `curl -fsSL https://open-jarvis.github.io/OpenJarvis/install.sh | bash` (Windows: `irm … install.ps1 | iex`; también hay instalador de escritorio). — README
- `jarvis connect gdrive`: «one OAuth covers Gmail / Calendar / Tasks». — README
- Preset `morning-digest`: «Spoken daily briefing from email, calendar, health, news» con audio TTS. — README
- No pide suscripción: el camino por defecto usa un modelo local (la nube es opcional).

## Lo que sorprende
Un «Jarvis» de verdad, hecho en Stanford, gratis y corriendo en tu propia computadora.

## El proceso, paso a paso
1. Pegas una línea en la terminal → se instala con su modelo local.
2. Conectas Gmail y calendario.
3. Activas el resumen de la mañana → te lo cuenta en voz alta.
